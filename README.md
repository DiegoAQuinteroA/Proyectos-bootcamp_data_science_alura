# 📊 Data Science Portfolio

> **Colección de proyectos desarrollados durante mi formación en Ciencia de Datos en el Bootcamp DS3 de Alura Latam.**

Bienvenido a mi portafolio de proyectos de **Data Science**. Este repositorio reúne los trabajos prácticos que desarrollé durante mi formación, aplicando técnicas de análisis de datos, estadística, visualización, aprendizaje automático y procesamiento de lenguaje natural mediante Python.

El objetivo de este repositorio es documentar mi evolución como Analista de Datos, mostrar la aplicación práctica de los conocimientos adquiridos y servir como portafolio profesional.

---

## 🚀 Acerca de este portafolio

Durante el Bootcamp desarrollé múltiples proyectos aplicando metodologías de análisis de datos desde la obtención y limpieza de la información hasta la construcción de modelos de Machine Learning.

En este repositorio encontrarás ejercicios prácticos y proyectos organizados por áreas de estudio, siguiendo el recorrido completo de la formación.
